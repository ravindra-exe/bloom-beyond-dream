# 2 remix of Bloom Haven

Create an award-winning immersive flower-themed website that feels magical, alive, and cinematic.

Core Concept:

A giant enchanted flower garden where every flower is a gateway to a unique interactive world. The experience should feel like stepping into a dream rather than browsing a website.

Visual Style:

- Luxury botanical aesthetic

- Soft peach, blush pink, ivory, cream, lavender, and gold accents

- Hyper-realistic flowers mixed with subtle fantasy elements

- Premium Apple-level design quality

- Editorial typography with elegant spacing

- No generic template appearance

Hero Section:

- Massive 3D floral composition occupying most of the screen

- Layers of peonies, lilies, cherry blossoms, orchids, daisies, petals, leaves, and fruits

- Flowers float at different depths creating strong parallax

- Petals gently drift through the air

- Mouse movement creates natural depth reactions

- Smooth bloom animation on page load

- Cinematic lighting with soft shadows

Scroll Experience:

- Scroll acts as a journey through the garden

- Camera smoothly travels between giant flowers

- Each flower reveals a hidden fantasy world

- Seamless transitions between sections

- No abrupt page jumps

Interactive Flower Worlds:

1. Crystal Flower

   - Glowing crystals growing inside petals

   - Reflections and sparkling particles

   - Floating glass fragments

2. Moonlight Flower

   - Bioluminescent plants

   - Fireflies and glowing pollen

   - Deep blue night atmosphere

3. Sky Flower

   - Floating islands among clouds

   - Birds, butterflies, and wind particles

   - Infinite dreamy horizon

4. Ocean Flower

   - Underwater floral kingdom

   - Jellyfish, bubbles, and coral structures

   - Light rays passing through water

5. Golden Flower

   - Warm golden sunlight

   - Floating pollen particles

   - Luxurious premium atmosphere

Animations:

- GSAP ScrollTrigger

- React Three Fiber

- Three.js

- WebGL shaders

- Smooth 60 FPS animations

- Petal physics

- Depth-based parallax

- Hover interactions

- Blooming flowers

- Floating particles

- Organic movement everywhere

UI Design:

- Minimal navigation

- Glassmorphism accents

- Elegant microinteractions

- Floating menu

- Smooth transitions

- Premium typography

- Responsive design

Technical Requirements:

- Next.js

- React Three Fiber

- Three.js

- GSAP

- Framer Motion

- Modular architecture

- Optimized performance

- Mobile responsive

- SEO friendly

Goal:

Create a website that looks worthy of Awwwards Site of the Day, feels magical, premium, immersive, and unforgettable, making visitors spend minutes exploring the flower worlds instead of seconds scrolling past.  add  camera in it so user perform operation like it all 2d but it feel 3d ok
